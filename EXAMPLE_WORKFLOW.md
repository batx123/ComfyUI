"# ComfyUI Deployment - Example Workflow\n\nThis document demonstrates a complete end-to-end workflow for deploying and using ComfyUI with the provided Kubernetes scripts.\n\n## Scenario: Production Deployment\n\nYou want to deploy ComfyUI to a Kubernetes cluster with:\n- GPU support for model inference\n- Persistent storage for models and outputs\n- Automatic scaling\n- Web access via LoadBalancer\n\n## Step-by-Step Workflow\n\n### Phase 1: Preparation\n\n```bash\n# 1. Check cluster connectivity\nkubectl cluster-info\nkubectl get nodes -o wide\n\n# 2. Verify required components\nkubectl get pods -n kube-system | grep -E 'coredns|metrics-server|nvidia-device-plugin'\n\n# 3. Check available storage classes\nkubectl get storageclass\n```\n\n### Phase 2: Initial Deployment\n\n```bash\n# 1. Navigate to script directory\ncd scripts/\n\n# 2. Run the comprehensive deployment script\n./deploy-kubernetes.sh\n\n# 3. Watch deployment progress\nkubectl get pods --namespace=comfyui -w\n\n# 4. Wait for deployment to complete\nkubectl rollout status deployment/comfyui-gpu --namespace=comfyui\n```\n\n### Phase 3: Verification\n\n```bash\n# 1. Check all resources are created\nkubectl get all --namespace=comfyui\n\n# 2. Check pod status and health\nkubectl get pods --namespace=comfyui\n\n# 3. Check resource allocation\nkubectl describe pod -l app=comfyui --namespace=comfyui\n\n# 4. Verify service endpoint\nkubectl get endpoints comfyui --namespace=comfyui\n```\n\n### Phase 4: Access Application\n\n```bash\n# Option 1: Port Forwarding (Recommended for testing)\n./port-forward.sh\n\n# Now access at: http://localhost:8188\n# Open browser and navigate to: http://localhost:8188\n\n# Option 2: Get LoadBalancer IP\nkubectl get svc comfyui --namespace=comfyui -o wide\n\n# Option 3: If using Ingress\nkubectl get ingress --namespace=comfyui\n```\n\n### Phase 5: Monitoring\n\n```bash\n# 1. Check application logs\nkubectl logs -f deployment/comfyui-gpu --namespace=comfyui\n\n# 2. Monitor resource usage\nkubectl top pods --namespace=comfyui\n\n# 3. Check node resource availability\nkubectl top nodes\n\n# 4. View deployment metrics\nkubectl get deployment comfyui-gpu --namespace=comfyui -o yaml | grep -A 10 'resources'\n```\n\n### Phase 6: Scaling\n\n```bash\n# 1. Check current replicas\nkubectl get deployment comfyui-gpu --namespace=comfyui\n\n# 2. Scale to 2 replicas (for high availability)\nkubectl scale deployment comfyui-gpu --namespace=comfyui --replicas=2\n\n# 3. Monitor scaling process\nkubectl get pods --namespace=comfyui -w\n\n# 4. Or enable HPA for auto-scaling\nkubectl apply -f k8s/hpa.yaml\nkubectl get hpa --namespace=comfyui\n```\n\n### Phase 7: Troubleshooting\n\n```bash\n# Run comprehensive diagnostics\n./troubleshoot.sh\n\n# Common troubleshooting commands:\n\n# Check pod events\nkubectl describe pod <pod-name> --namespace=comfyui\n\n# Check container logs\nkubectl logs <pod-name> --namespace=comfyui\n\n# Check container state\nkubectl get pod <pod-name> --namespace=comfyui -o yaml | grep -A 20 'state'\n\n# Check previous container logs (for crash recovery)\nkubectl logs --previous <pod-name> --namespace=comfyui\n\n# Check PVC status\nkubectl get pvc --namespace=comfyui\n\n# Check storage events\nkubectl describe pvc <pvc-name> --namespace=comfyui\n```\n\n### Phase 8: Maintenance\n\n```bash\n# 1. Check for updates\nkubectl get deployment comfyui-gpu --namespace=comfyui -o jsonpath='{.spec.template.spec.containers[*].image}'\n\n# 2. Update to latest version (edit deployment file first)\nkubectl apply -f k8s/deployment-gpu.yaml\n\n# 3. Perform rolling update\nkubectl set image deployment/comfyui-gpu comfyui=your-image:latest --namespace=comfyui\n\n# 4. Monitor rollout\nkubectl rollout status deployment/comfyui-gpu --namespace=comfyui\n\n# 5. Cleanup old pods (after rollout completes)\nkubectl get pods --namespace=comfyui --sort-by=.metadata.creationTimestamp\n```\n\n## Scenario: Development Environment\n\n### Quick Setup (5 minutes)\n\n```bash\n# 1. Create a development namespace\nkubectl create namespace comfyui-dev\n\n# 2. Apply minimal configuration\nkubectl apply -f k8s/pvc-storage.yaml -n comfyui-dev\nkubectl apply -f k8s/deployment-gpu.yaml -n comfyui-dev\n\n# 3. Use port-forwarding\nkubectl port-forward deployment/comfyui-gpu 8188:8188 -n comfyui-dev\n\n# 4. Access at http://localhost:8188\n```\n\n## Scenario: GPU Node Configuration\n\n### If Using GPU Nodes\n\n```bash\n# 1. Check if GPU nodes are labeled\nkubectl get nodes --show-labels | grep -E 'nvidia|gpu|accelerator'\n\n# 2. Verify GPU availability\nkubectl get nodes -o json | jq '.items[] | .status.allocatable | {\"nvidia.com/gpu\": .\"nvidia.com/gpu\"}'\n\n# 3. Check NVIDIA driver\nkubectl exec -it <pod-name> --namespace=comfyui -- nvidia-smi\n\n# 4. Verify GPU resource allocation\nkubectl describe pod <pod-name> --namespace=comfyui | grep -A 5 'GPU'\n```\n\n## Scenario: Backup and Recovery\n\n```bash\n# 1. Backup models\nkubectl cp comfyui/<pod-name>:/models ./models-backup-$(date +%Y%m%d)\n\n# 2. Backup configuration\nkubectl get configmap comfyui-config --namespace=comfyui -o yaml > config-backup-$(date +%Y%m%d).yaml\n\n# 3. Create full backup script\ncat > backup.sh << 'EOF'\n#!/bin/bash\nBACKUP_DIR="comfyui-backup-$(date +%Y%m%d-%H%M%S)\"\nmkdir -p $BACKUP_DIR\n\n# Backup models\nkubectl cp comfyui/<pod-name>:/models $BACKUP_DIR/models\n\n# Backup configuration\nkubectl get configmap comfyui-config --namespace=comfyui -o yaml > $BACKUP_DIR/config.yaml\n\n# Backup PVC\nkubectl get pvc comfyui-model-storage --namespace=comfyui -o yaml > $BACKUP_DIR/pvc.yaml\n\necho \"Backup completed: $BACKUP_DIR\"\nEOF\nchmod +x backup.sh\n./backup.sh\n```\n\n## Scenario: Disaster Recovery\n\n```bash\n# 1. Verify backup exists\nls -la comfyui-backup-*/\n\n# 2. Restore configuration\nkubectl apply -f config-backup.yaml\n\n# 3. Restore models\n# Copy models to host first, then recreate pod\n\n# 4. Re-deploy application\nkubectl apply -f k8s/\n\n# 5. Verify restoration\nkubectl get pods --namespace=comfyui\nkubectl logs -f deployment/comfyui-gpu --namespace=comfyui\n```\n\n## Monitoring and Alerts\n\n### Set Up Basic Alerts\n\n```bash\n# Create alert for pod restarts\nkubectl create alertmanagerconfig restart-alerts --namespace=comfyui << 'EOF'\napiVersion: v1\nkind: AlertmanagerConfig\nmetadata:\n  name: restart-alerts\n  namespace: comfyui\nspec:\n  route:\n    groupBy: ['alertname', 'cluster', 'service']\n    groupWait: 30s\n    groupInterval: 5m\n    repeatInterval: 12h\n    receiver: 'slack'\n  receivers:\n    - name: 'slack'\n      slack_configs:\n        - api_url: '<SLACK_WEBHOOK_URL>'\n          text: '{{ range .Alerts }}{{ .Annotations.description }}{{ end }}'\nEOF\n```\n\n### Resource Usage Alerts\n\n```yaml\n# Example HPA configuration\napiVersion: autoscaling/v2\nkind: HorizontalPodAutoscaler\nmetadata:\n  name: comfyui-hpa\n  namespace: comfyui\nspec:\n  scaleTargetRef:\n    apiVersion: apps/v1\n    kind: Deployment\n    name: comfyui-gpu\n  minReplicas: 1\n  maxReplicas: 5\n  metrics:\n  - type: Resource\n    resource:\n      name: cpu\n      target:\n        type: Utilization\n        averageUtilization: 70\n  - type: Resource\n    resource:\n      name: memory\n      target:\n        type: Utilization\n        averageUtilization: 80\n  - type: Pods\n    pods:\n      metric:\n        name: nvidia_gpu_utilization\n      target:\n        type: AverageValue\n        averageValue: 60\n```\n\n## Daily Operations Checklist\n\n```bash\n# Daily Checks\n./troubleshoot.sh                    # Run diagnostics\nkubectl get pods --namespace=comfyui # Check pod health\nkubectl top pods --namespace=comfyui # Check resource usage\nkubectl logs --tail=100 deployment/comfyui-gpu --namespace=comfyui # Check recent logs\n\n# Weekly Checks\nkubectl describe nodes --namespace=comfyui # Check node health\nkubectl get pvc --namespace=comfyui # Check storage status\nkubectl get hpa --namespace=comfyui # Check HPA status\nkubectl get events --namespace=comfyui --sort-by='.lastTimestamp' # Review recent events\n\n# Monthly Checks\nReview backup logs and restore procedures\nUpdate dependencies and security patches\nReview resource allocation and scaling policies\nUpdate documentation\n```\n\n## Best Practices Checklist\n\n- [ ] Always test deployments in staging first\n- [ ] Monitor resource usage before scaling\n- [ ] Implement backup procedures for model storage\n- [ ] Use Kubernetes Secrets for sensitive configuration\n- [ ] Set up proper logging and monitoring\n- [ ] Configure network policies for security\n- [ ] Regularly review and update images\n- [ ] Document any custom configurations\n- [ ] Test disaster recovery procedures\n- [ ] Monitor application performance and user feedback\n\n## Common Pitfalls and Solutions\n\n### Pitfall: Pods stuck in Pending state\n**Solution**: Check node availability and resources\n```bash\nkubectl describe pod <pod-name> --namespace=comfyui\n```\n\n### Pitfall: GPU not detected\n**Solution**: Verify NVIDIA driver and device plugin\n```bash\nkubectl exec -it <pod-name> --namespace=comfyui -- nvidia-smi\n```\n\n### Pitfall: Storage not bound\n**Solution**: Check PVC and storage class availability
```bash

```\n\n### Pitfall: High memory usage\n**Solution**: Adjust memory limits and monitor
